# GrammaireEtLangage
TP de grammaire et langage


Lancer le make, puis lancer le ./grammmaireEtLangage

Pour lancer les tests commenter la zone entre les commentaires main et decomenter les commentaires entre les commentaires "test unitaires", relancer le make puis lancer le programme (./grammaireEtLangage)

Il y a aussi un make clean pour nettoyer les fichiers de sortie ainsi que l'executable
